# 1. Visão Geral do NestJS

## O que é
É um framework completo para desenvolvimento backend em Node.js e TypeScript.

## Características
- Arquitetura **modular em camadas**.
- Uso de DTO (Data Transfer Object).
- Express como servidor HTTP.
- Uso de decorators.
- Dependency Injection (DI).
- Bom para projetos de médio e grande porte.
